# AI 模型成本核算工具

这个 skill 用于把模型与 Agent 的使用量换算为成本、产能与交付风险，避免只看 token 单价而忽略限流、生命周期与人工交付成本。

## 结构说明

- `SKILL.md`：核算方法与口径规则。
- `references/volcengine.md`：火山引擎价目快照。
- `scripts/video_cost.py`：视频成本计算器。

目录中还包含多厂商模型价格、基础设施价格快照及对应的计算脚本。

## 用法示例

列出支持的视频模型与参数：

```bash
python3 scripts/video_cost.py --list
```

在该目录内运行即可。脚本会根据其引用的价格快照输出成本、限流校验与模型生命周期提示。

## 设计原则

1. **价格只写进 references，不写进方法。** `SKILL.md` 固化核算框架与判断规则；会变动的报价集中在 `references/`，便于更新与追溯。
2. **限流是产能天花板。** 单价能说明花多少钱，RPM、TPM 与并发决定任务实际上能否跑得动。
3. **算力成本不等于交付成本。** 客户交付还可能包含人工审核、事实核对、合规、本地化与返工，不能把机器账单直接当作项目报价。
